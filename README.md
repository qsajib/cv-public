# Public CV

This repository contains the public version of my curriculum vitae.

Private contact information and referee details are omitted from this
version.

## Structure

- `cv_sajib_mqu_public.tex` — main CV source
- `cv_sajib_mqu_public.pdf` — compiled public CV
- `smqucv.bbx` — custom BibLaTeX bibliography style
- `bibliography/publications.bib` — publication database

## Build

Compile with:

```bash
make
```

The CV is built with LuaLaTeX via `latexmk`.
